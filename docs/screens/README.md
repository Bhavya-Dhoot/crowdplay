# Screenshots

Generated by the Playwright suite (`src/tests/e2e/6-screens.spec.ts`, plus `4-judge` and `7-links`) against a
production build in **mock modes** (`REALTIME_MODE=mock`, `LLM_MODE=mock`, `TIMING_SCALE=0.3`). Every state is real
app output driven by scripted test players — no doctored responses.

Honesty notes:
- Players in these images are automated test browsers, not real people. Bots appear only in `try-*` (labelled 🤖).
- `impact-*.png` shows aggregates of the **test run's own scripted players**. It demonstrates the page, not traction.
  Do not use it as evidence of real usage; take a fresh `/impact` capture after real sessions.
- Options, narration and prompts come from the deterministic mock distiller/narrator, not a live LLM.

Naming: `<page>[-<phase>]-<width>x<height>.png` at 390×844 (phone) and 1440×900 (desktop);
`screen-obs-1920x1080.png` is the transparent OBS overlay (`/screen/CODE?obs=1`).
