# Polish wave (2026-11-17, after the live Nexconn + OpenAI runs)

Goal (founder): extensive end-to-end testing; evaluate and improve; a unique, judge-appealing, very polished and fun
design (Apple HIG skill + Meta Astryx as sources); no friction; optimise latency, queries and model cost/performance.

Constraint: design coherence across parallel page agents, without breaking the frozen behaviour (data-testids,
routes, PublicState) that the e2e + live suites rely on.

Failure modes:
- Page agents restyle against primitives that are still changing -> design-system agent goes first (W-A), page
  agents (W-B) start only after its report; primitives keep backward-compatible props.
- A restyle breaks a test hook -> e2e suite (10 specs) + live spec re-run in W-C; agents must keep every testid.
- Polish adds weight -> Lighthouse re-run on / and /play (gates: a11y >= 95, perf >= 85).
- Perf changes alter behaviour -> backend perf agent keeps all unit/integration tests green and adds a test per change.
- Reload storms on the shared dev server while several agents edit -> agents verify with throwaway Playwright
  scripts and tolerate reloads; final evidence comes from production builds only.

Waves:
- W-0 audits (done/running): design sources (plans/design-sources.md), perf audit (plans/perf-audit.md),
  judge walkthrough (plans/ux-audit.md). Model cost/perf: gpt-5.4-mini kept (benchmarked vs nano and 4o-mini).
- W-A design system v2 + landing (one agent) || backend perf quick wins (one agent, no UI files).
- W-B page restyles in parallel: player (/join /play /me), screen, host, try + story/impact/how-it-works.
- W-C QA: e2e x3, live:check, Lighthouse, screenshots, docs; orchestrator review + final evaluation.

Ledger:
- Design direction + spec (plans/design-v2.md): orchestrator — it is the architecture of the look; agents implement.
- Audits: Sonnet agents, read-only, verifiable against the files/screens they cite.
- Implementation: Sonnet agents with disjoint file ownership, checked by tsc/lint/tests + orchestrator screenshots.
- Final verify, live run, evaluation write-up: orchestrator.
